# Zero to Dev (Personal)

A personal CS and cybersecurity mastery app built for Moe and his brother.

## Tech Stack
- Next.js 15
- Supabase (PostgreSQL + Auth)
- Tailwind CSS
- Piston API for code execution
- Local CTF Labs

## Getting Started

1. Clone the repo
2. Run `npm install`
3. Run `npm run dev`
4. Make sure to link your local Supabase by running `npx supabase start`
